# 第 05 章：向量嵌入与语义检索

## 5.1 本章目标

实现 `embed.py`，完成：

```
SQLite chunks  →  embedding  →  Chroma 向量库
用户问题       →  向量检索    →  相关 chunk 列表
```

验收：问「吃饭」能召回含「火锅」「聚餐」的 chunk，即使原文没出现「吃饭」二字。

## 5.2 Embedding 原理速览

```
文本 "今天吃了火锅"  →  模型  →  [0.12, -0.34, 0.56, ...]  (512维向量)
```

- 语义相近的文本，向量在空间中的距离更近
- 检索时：把问题也转成向量，找距离最近的 chunk 向量

## 5.3 加载嵌入模型

```python
"""向量嵌入与检索。"""

from sentence_transformers import SentenceTransformer
from src.store import load_config


_model = None


def get_embedding_model() -> SentenceTransformer:
    global _model
    if _model is None:
        cfg = load_config()
        model_name = cfg["embedding"]["model"]
        print(f"加载嵌入模型: {model_name} ...")
        _model = SentenceTransformer(model_name)
    return _model


def embed_texts(texts: list[str]) -> list[list[float]]:
    model = get_embedding_model()
    cfg = load_config()
    batch_size = cfg["embedding"]["batch_size"]
    embeddings = model.encode(texts, batch_size=batch_size, show_progress_bar=True)
    return embeddings.tolist()
```

首次运行会下载模型（`bge-small-zh-v1.5` 约 100MB），之后会缓存到本地。

## 5.4 写入 Chroma

```python
import chromadb
from src.store import load_config, resolve_path, get_db


def get_chroma_collection():
    cfg = load_config()
    chroma_dir = str(resolve_path(cfg["data"]["chroma_dir"]))
    client = chromadb.PersistentClient(path=chroma_dir)
    return client.get_or_create_collection(
        name="diary_chunks",
        metadata={"hnsw:space": "cosine"},  # 余弦相似度
    )


def index_all_chunks():
    """把 SQLite 中所有 chunk 嵌入并写入 Chroma。"""
    conn = get_db()
    rows = conn.execute("SELECT id, date, text, source_file FROM chunks").fetchall()
    conn.close()

    if not rows:
        print("没有 chunk 可索引")
        return

    ids = [r["id"] for r in rows]
    texts = [r["text"] for r in rows]
    metadatas = [{"date": r["date"], "source_file": r["source_file"]} for r in rows]

    print(f"嵌入 {len(texts)} 个 chunk ...")
    embeddings = embed_texts(texts)

    collection = get_chroma_collection()
    # Chroma upsert：已存在则更新
    collection.upsert(
        ids=ids,
        embeddings=embeddings,
        documents=texts,
        metadatas=metadatas,
    )
    print(f"索引完成，共 {collection.count()} 条")
```

运行：

```bash
python -m src.embed
```

## 5.5 语义检索

```python
def search_similar(query: str, top_k: int | None = None) -> list[dict]:
    """向量检索，返回相关 chunk 列表。"""
    cfg = load_config()
    k = top_k or cfg["retrieval"]["top_k"]

    query_embedding = embed_texts([query])[0]
    collection = get_chroma_collection()

    results = collection.query(
        query_embeddings=[query_embedding],
        n_results=k,
        include=["documents", "metadatas", "distances"],
    )

    chunks = []
    for i in range(len(results["ids"][0])):
        chunks.append({
            "id": results["ids"][0][i],
            "text": results["documents"][0][i],
            "date": results["metadatas"][0][i]["date"],
            "distance": results["distances"][0][i],
            "score": 1 - results["distances"][0][i],  # 余弦距离转相似度
        })
    return chunks
```

## 5.6 检索结果解读

| 字段 | 含义 |
|------|------|
| `distance` | 余弦距离，越小越相似（0 = 完全相同） |
| `score` | `1 - distance`，越大越相似 |
| `top_k` | 返回条数，默认 20 |

经验阈值（需根据你的数据调试）：

- `score > 0.6`：高度相关
- `0.4 – 0.6`：可能相关
- `< 0.4`：大概率不相关

## 5.8 增量索引

新日记导入后，只索引新增 chunk，不必全量重建：

```python
def index_new_chunks(chunk_ids: list[str]):
    """只嵌入并写入指定 id 的 chunk。"""
    conn = get_db()
    placeholders = ",".join("?" * len(chunk_ids))
    rows = conn.execute(
        f"SELECT id, date, text, source_file FROM chunks WHERE id IN ({placeholders})",
        chunk_ids,
    ).fetchall()
    conn.close()

```

在 `ingest.py` 中记录本次新增的 chunk id，导入后调用 `index_new_chunks`。

## 5.9 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 召回结果不相关 | query 太笼统 | 具体化 query，如「吃饭 餐厅 美食」 |
| 模型下载失败 | 网络 | 设 `HF_ENDPOINT=https://hf-mirror.com` |
| 索引很慢 | 首次下载模型 | 正常，200 chunk 约 1–2 分钟 |
| 相同文本 score 不是 1.0 | 浮点精度 | 可忽略 |
