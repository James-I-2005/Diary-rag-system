# 第 06 章：结构化标签提取

## 6.1 本章目标

实现 `extract_tags.py`，用 LLM 为每个 chunk 提取结构化标签，存入 SQLite。

这是本项目**区别于普通 RAG** 的关键——让系统能**计数、过滤、聚合**。

验收：每个 chunk 有 `topics`、`food_mentions`、`is_touching_moment` 等字段；能 SQL 查询「感动瞬间次数」。

## 6.2 标签 schema 设计

根据你的三类查询需求，设计字段：

```python
TAG_SCHEMA = {
    "topics": [],              # 主题：吃饭、运动、工作、朋友、旅行...
    "activities": [],          # 具体活动：吃火锅、跑步、看电影...
    "emotions": [],            # 情绪：开心、难过、感动、焦虑...
    "food_mentions": [],       # 食物：火锅、拉面、饭团...
    "people": [],              # 人物：朋友名、家人...
    "is_touching_moment": False,   # 是否感动瞬间
    "touching_summary": "",        # 感动事件一句话摘要（仅 is_touching_moment=true 时填）
}
```

存入 SQLite 的 `chunk_tags` 表：

```sql
CREATE TABLE IF NOT EXISTS chunk_tags (
    chunk_id          TEXT PRIMARY KEY REFERENCES chunks(id),
    topics            TEXT,    -- JSON 数组字符串
    activities        TEXT,
    emotions          TEXT,
    food_mentions     TEXT,
    people            TEXT,
    is_touching_moment INTEGER DEFAULT 0,
    touching_summary  TEXT,
    extracted_at      TEXT DEFAULT (datetime('now'))
);
```

## 6.3 LLM 提取 Prompt

```python
EXTRACT_PROMPT = """分析以下日记片段，提取结构化信息。

日记内容：
---
{text}
---

日期：{date}

请严格返回 JSON，不要其他文字：
{{
  "topics": ["主题1", "主题2"],
  "activities": ["活动1"],
  "emotions": ["情绪1"],
  "food_mentions": ["食物1"],
  "people": ["人物1"],
  "is_touching_moment": false,
  "touching_summary": ""
}}

规则：
- topics 从以下选：吃饭、运动、工作、学习、朋友、家人、旅行、娱乐、健康、其他
- is_touching_moment：是否包含让人感动、温暖、落泪、心里一暖等时刻
- touching_summary：仅 is_touching_moment 为 true 时填写，一句话概括
- 没有相关内容则对应字段为空数组或 false
"""
```

## 6.4 调用 LLM

使用 OpenAI 兼容接口（Ollama / 云端 API 均可）：

```python
import json
from openai import OpenAI
from src.store import load_config


def get_llm_client() -> OpenAI:
    cfg = load_config()["llm"]
    return OpenAI(base_url=cfg["base_url"], api_key=cfg["api_key"])


def extract_tags_for_chunk(text: str, date: str) -> dict:
    client = get_llm_client()
    cfg = load_config()["llm"]

    prompt = EXTRACT_PROMPT.format(text=text, date=date)
    response = client.chat.completions.create(
        model=cfg["model"],
        messages=[{"role": "user", "content": prompt}],
        temperature=0.1,          # 低温度，输出稳定
        response_format={"type": "json_object"},
    )

    raw = response.choices[0].message.content
    return json.loads(raw)
```

> **Ollama 注意**：`response_format` 需要 Ollama 0.5+ 且模型支持 JSON mode。若报错，去掉 `response_format`，在 prompt 末尾加强「只返回 JSON」。

## 6.5 批量提取与存储

```python
import json
from src.store import get_db


def save_tags(chunk_id: str, tags: dict, conn):
    conn.execute(
        """INSERT OR REPLACE INTO chunk_tags
           (chunk_id, topics, activities, emotions, food_mentions,
            people, is_touching_moment, touching_summary)
           VALUES (?, ?, ?, ?, ?, ?, ?, ?)""",
        (
            chunk_id,
            json.dumps(tags.get("topics", []), ensure_ascii=False),
            json.dumps(tags.get("activities", []), ensure_ascii=False),
            json.dumps(tags.get("emotions", []), ensure_ascii=False),
            json.dumps(tags.get("food_mentions", []), ensure_ascii=False),
            json.dumps(tags.get("people", []), ensure_ascii=False),
            1 if tags.get("is_touching_moment") else 0,
            tags.get("touching_summary", ""),
        ),
    )


def extract_all_tags():
    conn = get_db()
    # 只处理尚未提取的 chunk
    rows = conn.execute("""
        SELECT c.id, c.date, c.text
        FROM chunks c
        LEFT JOIN chunk_tags t ON c.id = t.chunk_id
        WHERE t.chunk_id IS NULL
    """).fetchall()

    print(f"待提取: {len(rows)} 个 chunk")
    for i, row in enumerate(rows):
        print(f"  [{i+1}/{len(rows)}] {row['id']} ...")
        try:
            tags = extract_tags_for_chunk(row["text"], row["date"])
            save_tags(row["id"], tags, conn)
            conn.commit()
        except Exception as e:
            print(f"    失败: {e}")

    conn.close()
    print("标签提取完成")
```

运行：

```bash
python -m src.extract_tags
```

200 个 chunk × 本地 Qwen2.5-7B，大约 30–60 分钟。可先用 10 个 chunk 测试 prompt 质量。

## 6.7 Prompt 调优技巧

| 问题 | 调整 |
|------|------|
| 漏标感动瞬间 | 在 prompt 中给 2–3 个正例 |
| topics 太泛 | 限定枚举列表，不允许自造 |
| JSON 格式错误 | 降低 temperature；加重「只返回 JSON」 |
| 提取太慢 | 换更小模型做提取（qwen2.5:3b）；或批量 API |

## 6.8 规则补充（可选）

对明确模式可用正则，减少 LLM 调用：

```python
import re

FOOD_KEYWORDS = ["火锅", "拉面", "饭团", "外卖", "餐厅", "做饭", "早餐", "午餐", "晚餐"]

def rule_based_food_check(text: str) -> list[str]:
    return [kw for kw in FOOD_KEYWORDS if kw in text]
```

可将规则结果与 LLM 结果合并，作为校验或 fallback。
