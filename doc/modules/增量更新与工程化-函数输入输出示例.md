# 增量更新与工程化 · 函数签名与输入输出示例

基于 `data/diary/sample.md`。每个函数只举 1 个例子。

假设：`sample.md` 已全量导入；目录里**新出现**一篇 `2025-07.md`（含 `# 2025-07-01` 一篇短日记）。

---

## 前置数据（更新前）

| ingest_log.source_file | file_hash（节选） | chunk_count |
|------------------------|-------------------|-------------|
| `sample.md` | `c13d38fc…650a` | 4 |

| chunks.id | date | source_file | text 节选 |
|-----------|------|-------------|-----------|
| `2025-06-15_0` | 2025-06-15 | `sample.md` | …吃了火锅… |
| `2025-06-16_0` | 2025-06-16 | `sample.md` | …便利店饭团… |
| `2025-06-18_0` | 2025-06-18 | `sample.md` | …番茄炒蛋… |
| `2025-06-25_0` | 2025-06-25 | `sample.md` | …改了 PPT… |

新文件（尚未进库）：`data/diary/2025-07.md` → 将产生 `2025-07-01_0`。

---

## 模块 1：变更检测与增量导入

调用链：`file_hash` →（若变更）`delete_chunks_by_source` → `save_chunks` → 写 `ingest_log`  
对外入口：`ingest_incremental`

### `file_hash(filepath: Path) -> str`

对日记文件做 MD5，用于判断相对 `ingest_log` 是否有变更。

```python
# 输入
filepath = Path("data/diary/sample.md")
# 输出
result = "c13d38fceec82fee9e180c19b1bc650a"
```

### `delete_chunks_by_source(source_file: str, conn: sqlite3.Connection) -> None`

文件变更重导入前，按 `source_file` 删掉旧 chunk 与对应 `chunk_tags`。

```python
# 输入
source_file = "sample.md"
conn = get_db()
# 输出
result = None
# 副作用：DELETE chunk_tags / chunks WHERE source_file = "sample.md"
```

### `ingest_incremental() -> list[str]`

扫描 `diary_dir` 下 `*.md`：hash 未变则跳过；新增或变更则重导入，返回**本次**新增的 chunk id 列表。

```python
# 输入（无参数；读 config + diary_dir + ingest_log）
# 输出
new_chunk_ids = ["2025-07-01_0"]
# sample.md hash 未变 → 跳过；仅处理 2025-07.md
```

## 模块 2：增量嵌入与标签

调用链（日常）：`index_new_chunks` → `extract_tags_for_ids`  
（由 `cmd_update` 在拿到 `new_chunk_ids` 后依次调用）

### `index_new_chunks(chunk_ids: list[str]) -> None`

只从 SQLite 取出指定 id，嵌入后 upsert 进 Chroma `diary_chunks`。

```python
# 输入
chunk_ids = ["2025-07-01_0"]
# 输出
result = None
# 副作用：Chroma upsert 1 条；打印「增量索引完成，本次 1 条，集合共 5 条」
```

### `extract_tags_for_ids(chunk_ids: list[str]) -> None`

对指定 chunk id 批量跑 LLM 标签提取，写入 / 覆盖 `chunk_tags`。

```python
# 输入
chunk_ids = ["2025-07-01_0"]
# 输出
result = None
# 副作用：chunk_tags 多一行，例如
# {"chunk_id": "2025-07-01_0", "food_mentions": ["…"], "is_touching_moment": 0, …}
```

## 模块 3：CLI 一键更新与路由

调用链：`cmd_update` → `ingest_incremental` → `index_new_chunks` → `extract_tags_for_ids`  
顶层：`main` 用 `argparse` 把 `"update"` 映射到 `cmd_update`，其它子串当问题交给 `generate_answer`

### `cmd_update() -> None`

增量更新三步走：导入 → 嵌入 → 标签；无新内容则提前返回。

```python
# 输入（无参数）
# 输出
result = None
# 副作用（有新文件时）：
# new_ids = ["2025-07-01_0"]
# index_new_chunks(new_ids); extract_tags_for_ids(new_ids)
# 控制台打印「1/3 …」「2/3 …」「3/3 …」「更新完成」
```

### `main() -> None`

解析 `command`（及可选 `rest`）：命中子命令则执行；否则拼成 `question` 调问答。

```python
# 输入（命令行等价）
# sys.argv ≈ ["main.py", "update"]
# 输出
result = None
# 副作用：调用 cmd_update()
```

## 对照

| 函数 | 输入例子 | 输出要点 |
|------|----------|----------|
| `file_hash` | `filepath=sample.md` | MD5 字符串 |
| `delete_chunks_by_source` | `source_file="sample.md"` | `None`；清旧 chunk/tags |
| `ingest_incremental` | （扫目录） | `new_chunk_ids=["2025-07-01_0"]` |
| `index_new_chunks` | `chunk_ids=[…]` | `None`；Chroma upsert |
| `extract_tags_for_ids` | `chunk_ids=[…]` | `None`；写 `chunk_tags` |
| `cmd_update` | （无） | `None`；串联上三步 |
| `main` | `update` | `None`；分发到 `cmd_update` |
