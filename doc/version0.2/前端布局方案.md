# Frontend Layout Specification

目标：

整体页面布局参考 ChatGPT 官方网页版（chat.openai.com）的交互方式和视觉结构，不需要完全一致，但整体布局、信息层级和交互模式保持一致。

---

# Overall Layout

整个页面采用左右布局。

```
+--------------------------------------------------------------+
| Sidebar          |                                            |
|                  |                                            |
|                  |                                            |
|                  |                                            |
|                  |            Chat Area                       |
|                  |                                            |
|                  |                                            |
|                  |                                            |
|                  |                                            |
+--------------------------------------------------------------+
```

左侧为 Sidebar。

右侧为 Chat Workspace。

整个页面占满浏览器。

---

# Sidebar（左侧）

固定宽度。

主要包含：

```
--------------------------------
LOGO

+ New Chat

--------------------------------

Conversation 1

Conversation 2

Conversation 3

...

--------------------------------

Settings（可选）

Profile（可选）

--------------------------------
```

功能：

- 新建聊天
- 展示历史 Conversation
- 点击切换 Conversation
- 当前 Conversation 高亮
- Sidebar 可以折叠（后续实现即可）

历史 Conversation：

仅显示：

- Conversation Title
- 最后更新时间（可选）

不需要展示消息内容。

---

# Chat Workspace（右侧）

右侧占据剩余全部空间。

结构：

```
-----------------------------------

Header（可选）

-----------------------------------

Scrollable Message Area

-----------------------------------

Input Area

-----------------------------------
```

整个 Workspace 使用 Flex Layout。

Message Area 自动占满剩余空间。

Input 固定在底部。

---

# Header

可以非常简单。

例如：

```
Memory Assistant
```

或者：

当前 Conversation Title。

暂时无需复杂功能。

---

# Message Area

整个聊天区域支持：

- 垂直滚动
- 自动滚动到底部
- Message 按时间顺序排列

布局：

```
User

Assistant

User

Assistant

...
```

---

# Message Bubble

采用 ChatGPT 风格。

User：

- 靠右（或统一居中均可）
- 有背景色

Assistant：

- 靠左
- 无背景或浅色背景

消息支持：

- Markdown
- Code Block
- 列表
- 引用

后续支持：

- Streaming Output

---

# Input Area

固定在页面底部。

整体布局：

```
+------------------------------------------------------+
|                                                      |
|                                                      |
|              Multiline Text Input                    |
|                                                      |
+------------------------------------------+-----------+
                                           |  Send     |
                                           +-----------+
```

特点：

- 多行输入
- Enter 发送
- Shift + Enter 换行
- 输入框自动增高
- 最多若干行后滚动

Send Button：

- 位于右侧
- 没有输入时禁用

---

# Conversation Switching

点击 Sidebar 中任意 Conversation：

应：

```
加载对应历史消息

↓

Message Area 更新

↓

Input 保持可用
```

不会刷新整个页面。

---

# New Chat

点击：

```
+ New Chat
```

行为：

```
创建新的 Conversation

↓

切换到新 Conversation

↓

聊天区域为空

↓

等待第一次输入
```

第一条消息发送后：

Conversation 自动生成标题。

（后端后续实现）

---

# Empty State

第一次进入新 Conversation：

聊天区域显示欢迎信息。

例如：

```
你好！

今天想回忆些什么？
```

下面可以放几个示例问题。

例如：

```
• 我第一次去东京是什么时候？

• 我去年夏天都做了什么？

• 有没有写过关于焦虑的日记？
```

点击后直接填充输入框。

---

# Scrolling Behavior

要求：

聊天时：

Assistant 输出完成：

自动滚动到底部。

用户发送消息：

自动滚动到底部。

用户手动向上浏览历史：

不要强制拉回底部。

---

# Responsive

桌面优先。

后续支持移动端。

Sidebar：

小屏幕可以隐藏。

---

# Visual Style

整体风格：

- 极简
- 留白充足
- 圆角
- 柔和阴影（可选）

避免：

- 花哨动画
- 多余装饰
- 复杂颜色

整体风格尽量接近 ChatGPT 官方网页。

---
