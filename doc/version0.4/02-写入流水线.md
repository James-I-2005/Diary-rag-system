# v0.4 写入流水线

> 目录来源可先走 **Extract Pipeline**（`05-extract-pipeline.md`）：扫盘 → Agent 定日期 → 正则/mtime 兜底 → Manifest → 再 ingest。

```text
（可选）extract → Manifest
ingest（或 ingest_from_manifest）→ chunks 表
    → paraphrase（LLM：chunk → 多行 rag-sentence）
    → rag_sentences 表
    → embed → Chroma diary_sentences
    →（可选）tags 仍挂 chunk
```

## 命令

```powershell
python main.py ingest
python main.py sentences          # 或 scripts/build_rag_sentences.py
python main.py index              # 现为索引 sentences（非 chunk）
python main.py tags
python main.py update             # 增量：ingest → sentences → index → tags
```

## 增量

仅对尚无 sentence 的 chunk 跑 paraphrase；`--force` 重跑。

## 配置

```yaml
paraphrase:
  max_sentences_per_chunk: 30
  model_version: "rag-sentence-v1"
  llm_role: "tags"
```
