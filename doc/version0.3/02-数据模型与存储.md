# v0.3 数据模型与存储

## 1. 设计原则

- **Raw Storage**：SQLite `chunks`（已有，不变）
- **View Storage**：SQLite `memory_views`（结构化 View 正文）
- **Vector Storage**：Chroma `diary_views`（View embedding，与 `diary_chunks` 并存）

最小检索单位在 ANN 层是 **View**；对外仍暴露 **chunk_id**，兼容 hydrate / Conversation trace。

## 2. SQLite：memory_views

```sql
CREATE TABLE IF NOT EXISTS memory_views (
    id TEXT PRIMARY KEY,              -- view_id，如 {chunk_id}_v0
    chunk_id TEXT NOT NULL REFERENCES chunks(id) ON DELETE CASCADE,
    view_type TEXT NOT NULL,          -- event|narrative|growth|identity|future_query
    content TEXT NOT NULL,
    date TEXT NOT NULL,
    source_file TEXT,
    created_at TEXT DEFAULT (datetime('now')),
    model_version TEXT DEFAULT 'v0.3'
);
CREATE INDEX IF NOT EXISTS idx_memory_views_chunk ON memory_views(chunk_id);
CREATE INDEX IF NOT EXISTS idx_memory_views_type ON memory_views(view_type);
CREATE INDEX IF NOT EXISTS idx_memory_views_date ON memory_views(date);
```

### view_type 枚举

| 类型 | 含义 |
|------|------|
| `event` | 发生了什么 |
| `narrative` | 事件意义/背景 |
| `growth` | 个人成长变化 |
| `identity` | 长期身份/价值观 |
| `future_query` | 未来可能被问到的抽象问法 |

### view_id 规则

`{chunk_id}_v{index}`，index 从 0 起，同 chunk 内唯一。

## 3. Chroma：diary_views

| 字段 | 说明 |
|------|------|
| `id` | view_id |
| `document` | view content |
| `embedding` | BGE 等（与 chunk 共用模型） |
| `metadata.chunk_id` | 关联 chunk |
| `metadata.view_type` | 类型 |
| `metadata.date` | 日记日期 |
| `metadata.source_file` | 来源文件 |

Collection 名：`diary_views`，space：`cosine`（与 `diary_chunks` 一致）。

## 4. 与 chunks 关系

```
chunks (1) ──< memory_views (N)
                │
                └──> Chroma diary_views (N vectors)
```

删除 chunk 时 CASCADE 删除 memory_views；Chroma 侧需同步 delete view ids。

## 6. 配置（config.yaml）

```yaml
memory_views:
  max_views_per_chunk: 6
  model_version: "v0.3"
  chroma_collection: "diary_views"
  extraction:
    llm_role: "tags"   # 与现有 LLM 角色复用
    batch_size: 8
```

