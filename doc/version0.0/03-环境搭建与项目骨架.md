# 第 03 章：环境搭建与项目骨架

## 3.1 环境要求

| 组件 | 版本 | 用途 |
|------|------|------|
| Python | 3.11+ | 主语言 |
| pip / uv | 最新 | 包管理 |
| Ollama（可选） | 最新 | 本地 LLM |
| Git | 任意 | 版本管理 |

检查 Python 版本：

```bash
python --version
# 应输出 Python 3.11.x 或更高
```

## 3.2 创建虚拟环境

在项目根目录 `Personal_Rag/` 下：

```bash
# Windows PowerShell
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# macOS / Linux
python -m venv .venv
source .venv/bin/activate
```

激活后，终端提示符前会出现 `(.venv)`。

## 3.3 安装依赖

创建 `requirements.txt`：

```text
# 核心
chromadb>=0.5.0
sentence-transformers>=3.0.0
sqlite-utils>=3.36

# LLM（本地 Ollama 或 OpenAI 兼容 API）
openai>=1.40.0
httpx>=0.27.0

# 工具
pyyaml>=6.0
python-dateutil>=2.9.0
rich>=13.7.0          # 终端美化输出
```

安装：

```bash
pip install -r requirements.txt
```

> **说明**：`sentence-transformers` 首次运行会自动下载 `bge-small-zh` 模型（约 100MB），需联网。

### 可选：安装 Ollama（本地 LLM）

1. 访问 https://ollama.com 下载安装
2. 拉取模型：

```bash
ollama pull qwen2.5:7b
```

3. 验证：

```bash
ollama run qwen2.5:7b "你好"
```

## 3.5 配置文件

`config.yaml`：

```yaml
# 路径
data:
  diary_dir: "data/diary"
  db_path: "data/diary.db"
  chroma_dir: "data/chroma"

# 切块
chunking:
  max_chars: 500        # 每块最大字符数
  overlap_chars: 50     # 块间重叠字符数

# 嵌入
embedding:
  model: "BAAI/bge-small-zh-v1.5"
  batch_size: 32

# 检索
retrieval:
  top_k: 20

# LLM（标签提取 & 回答生成）
llm:
  provider: "ollama"           # ollama | openai
  model: "qwen2.5:7b"
  base_url: "http://localhost:11434/v1"
  api_key: "ollama"            # ollama 不需要真实 key

# 日记格式
diary:
  date_pattern: "^# (\\d{4}-\\d{2}-\\d{2})"   # Markdown 日期标题
```

## 3.6 配置加载工具

在 `src/store.py` 中先写好配置加载（后续章节会扩展此文件）：

```python
"""存储层：配置加载、SQLite、Chroma 封装。"""

from pathlib import Path
import yaml

ROOT = Path(__file__).parent.parent


def load_config() -> dict:
    with open(ROOT / "config.yaml", encoding="utf-8") as f:
        return yaml.safe_load(f)


def resolve_path(relative: str) -> Path:
    return ROOT / relative
```

## 3.7 验证环境

创建 `scripts/check_env.py`（可选，用于一次性检查）：

```python
"""环境检查脚本。"""

def check():
    errors = []

    # Python 版本
    import sys
    if sys.version_info < (3, 11):
        errors.append(f"Python 需 3.11+，当前 {sys.version}")

    # 依赖
    for pkg in ["chromadb", "sentence_transformers", "yaml", "rich"]:
        try:
            __import__(pkg.replace("-", "_") if pkg == "yaml" else pkg)
        except ImportError:
            errors.append(f"缺少依赖: {pkg}")

    # 配置
    from src.store import load_config
    cfg = load_config()
    print("配置加载成功:", list(cfg.keys()))

    if errors:
        print("❌ 环境问题:")
        for e in errors:
            print(f"  - {e}")
    else:
        print("✅ 环境就绪")


if __name__ == "__main__":
    check()
```

运行：

```bash
python scripts/check_env.py
```

## 常见问题

| 问题 | 解决 |
|------|------|
| `Activate.ps1` 无法执行 | `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` |
| `sentence-transformers` 下载慢 | 设置 `HF_ENDPOINT=https://hf-mirror.com` 环境变量 |
| Ollama 连接失败 | 确认 `ollama serve` 在运行，默认端口 11434 |
