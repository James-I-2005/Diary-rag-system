# UI Design Prompt — Editorial Japanese Journal (Inspired by Zine)

You are a world-class product designer with expertise in editorial design, interaction design, and emotional user experience.

Design an original interface for an AI-powered journaling and memory visualization application.

The interface should capture the same calm, refined, editorial feeling found in the best modern journaling products, while remaining entirely original in its visual execution.

## Core Design Philosophy

This is **not** an AI product.

This is **not** a productivity app.

This is a quiet personal space where people return every evening to reflect on themselves.

Technology should disappear.

The interface should feel invisible.

The user's memories should become the visual focus.

Design with the mindset:

> Less Interface. More Story. More Silence. More Emotion.

---

## Overall Atmosphere

Imagine a blend of:

* Japanese editorial magazines
* Independent bookstores
* Premium printed books
* Handmade journals
* MUJI aesthetics
* Wabi-Sabi philosophy
* Slow living
* Soft morning light
* Natural paper

The experience should feel calm rather than exciting.

Warm rather than futuristic.

Elegant rather than decorative.

---

## Layout

Avoid dashboard layouts.

Avoid obvious cards.

Avoid heavy containers.

Instead:

* editorial page layouts
* flowing vertical rhythm
* generous margins
* asymmetric composition
* content-first hierarchy
* breathing space between sections

Every screen should resemble a magazine spread rather than an application.

---

## Typography

Typography is the primary design element.

Use hierarchy through:

* font size
* spacing
* weight
* rhythm

Avoid excessive bold text.

Paragraphs should feel comfortable to read.

Headings should never shout.

---

## Color System

Never use pure white.

Never use pure black.

Backgrounds should resemble paper.

Suggested palette:

* warm ivory
* soft cream
* oatmeal
* linen
* light stone
* warm gray
* fog
* muted sage
* charcoal

Accent colors should appear only occasionally and remain muted.

---

## Components

Every component should feel integrated into the page.

Avoid floating cards.

Avoid thick borders.

Avoid strong shadows.

Buttons should feel quiet.

Inputs should resemble writing on paper.

Icons should be extremely subtle.

Nothing should compete with the written content.

---

## Journal Experience

Journal entries should flow naturally down the page.

Entries should not feel boxed.

Use spacing and typography instead of containers.

Dates should be elegant and understated.

Photos should blend naturally into the reading flow.

The overall feeling should resemble reading a beautifully designed personal diary.

---

## AI Experience

Do not design a traditional chat interface.

Avoid speech bubbles.

Avoid chatbot aesthetics.

The AI should appear as a thoughtful companion whose reflections are woven naturally into the journal.

Responses should feel like margin notes, annotations, or gentle letters.

The AI should never dominate the page.

---

## Memory Visualization

Avoid dashboard charts.

Avoid colorful widgets.

Visualizations should resemble pages from a memory atlas.

Relationships, emotions, timelines, and reflections should feel integrated into the editorial layout.

Data should feel human rather than analytical.

---

## Motion

Animations should be subtle.

Soft fades.

Gentle movement.

Slow transitions.

Everything should feel like breathing.

No flashy effects.

---

## Things to Avoid

* Glassmorphism
* Neon gradients
* Vibrant colors
* Floating widgets
* Excessive rounded rectangles
* Heavy shadows
* SaaS dashboard layouts
* Generic AI interfaces
* Productivity app aesthetics
* Dribbble-style decoration
* Overly symmetrical layouts
* Identical spacing everywhere
* Visual clutter

---

## Goal

Design an interface that feels timeless.

Users should forget they are using software.

It should feel like opening a beautifully designed journal that quietly preserves memories, emotions, and conversations.

The interface should evoke warmth, reflection, humanity, and calm through typography, spacing, restraint, and atmosphere rather than visual effects.
