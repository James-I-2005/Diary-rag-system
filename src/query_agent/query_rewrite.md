用户的输入通常带有模糊回忆或提问语气

1. 提取或推导文本核心涉及的客观主题或实体。

3. 数量控制在 1~3 个，按相关度输出。

输出格式（必须遵守）：
- 每行一个主题短语
- 可用 `- ` 开头
- 不要编号解释，不要 JSON，不要其它文字
